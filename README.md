# Module_6_AI-Based-Handwritten-Digit-Generation-Using-GANs

Project Overview

This project implements a Generative Adversarial Network (GAN) using TensorFlow/Keras to generate handwritten digit images similar to MNIST.

Dataset

MNIST handwritten digit dataset from TensorFlow.

Technologies Used

1. Python

2. TensorFlow 2.x

3. Keras

4. NumPy

5. Matplotlib

Project Workflow

step1: Load Dataset

step2: Normalize Images

step3: Build Generator

step4: Build Discriminator

step5: Train GAN

step6: Generate Images
step7: Plot Loss Curves

Results

* Successfully generated handwritten digits.

* Visualized Generator and Discriminator losses.

Conclusion

GAN effectively learns image distributions and can generate synthetic handwritten digit images.
